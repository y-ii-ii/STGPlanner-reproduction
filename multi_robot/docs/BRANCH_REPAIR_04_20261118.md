# 分支探索第四版

第3次两车走出起始通道后仍常接近同一片前沿。早段234组约1秒间隔的同时派发采样中，177组的两个目标不足4米。任务支撑互斥只能避免争用同一份观测，两个不相交的任务仍可能位于同一支路。

在新任务的图距离与剩余观测收益评分之上加入软代价。末端5米图路共享较多样点、两个目标相距6米以内时，提高该竞标的代价。共同的初始通道不会仅因共享而被惩罚。新增代价用于排序，可达候选不会被删除。已执行任务优先保持原归属，旧轨迹、车身净空与停车确认沿用第3版。

用例验证同起点异支路不加代价，以及同时有两个可达候选时选择能与同伴分开的目标。在线评估记录双派发终点间距、实际轨迹、低增益路程和同一评分器的覆盖并集。

同一试次约442秒，车1开始沿33.287米图路前往新支路。60秒后图路只剩20.174米、车身已有可核对的位移，旧60秒执行期限仍将它打断，随后又重派同一目标。现在原始图路至少18米，实测位移至少2米且剩余图路已减少至少2米的派发，可在初次派发计算出的期限内续行。上限140秒，滚动重规划不延长期限，普通短路径和独立的停滞保护沿用原规则。
