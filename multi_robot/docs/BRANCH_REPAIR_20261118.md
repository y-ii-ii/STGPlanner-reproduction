# Scene4 分支探索闭环修复

上一轮第4次在探索约836.476至1075.132秒只新增一个评分格，两车累计行驶60.717米。跨过这段时间的17个派发中，融合图通行获准2,174次，本机接近带获准314次，原生前沿选点没有获准。车1反复选择相邻的185和186，车2反复选择163、174和193。若干派发在同一入口附近走了5至12米，最后以执行期限或局部规划受阻结束。

## 任务与分支

- 保留图距离可达竞标，以未观测支撑格数量作有界收益折扣。原先选择距离最近的新任务，已观测的支撑格现在不给收益。
- 一个派发的观测范围、版本和车号仍固定。原任务重命名或分裂时，只有支撑相似且在旧目标附近存在新鲜、连通的入口，才接续旧派发。交接继续通过STOP和物理停车ACK。
- 局部反馈携带与已签发范围绑定的部分观察计数。距视点3米内，连续12秒没有新观测或目标接近、累计又走过2.4米时，按无进展停车。因局部几何失败或无进展延后再派发的视点，以位置及观测支撑共同识别，90秒后可重试。它只限制同一车，既不宣告任务结束也不改变评分。
- 每个任务保留原边界入口，并在附近连通的开阔自由栅格有候选时提供后撤观察位。根到各视点的路径共享一次本机四连通搜索。其他机器人收到的是拓扑图增量。

## 本机路径

- 融合图通行在有限弧段内把旧路径根对齐到实测位置。全车扫掠通过的执行前缀还要沿分配路线取得进展，或拉近任务目标距离。已认证的低速脱困单独处理。
- 接近任务时优先评估能看到此前遮挡的剩余边界的本机视点。视线检查和车身扫掠都使用本机地图。近墙、未知和急弯仍受原执行约束。
- 没有新增观测时，短时间位移不当作探索收益。部分观测反馈只影响进展监测，完整观测证明和停车确认仍独立。

## 验证口径

四次上限由独立账本管理。原Scene4、速度上限、评分器与0.4 m格不变。离线检查包含重复入口、范围固定的别名接续、路径交叉不跳段、遮挡与视点收益，以及原停止和交通安全回归。
