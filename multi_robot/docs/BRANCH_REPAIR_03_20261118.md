# 分支探索第三版

第2次车2在起始通道末端因 `BODY_NO_ROUTE_PROGRESS` 请求停车。第一次和重试的停止窗口均超时。约163秒时速度门首次发出匹配最后旧nonce的有效证明，迟于约45秒的截止时间。旧策略此后一直保持故障。车1恢复推进后，车2仍无法领取有效任务。这次在约309秒主动诊断收尾，新的最终停车请求获得两车动作回执。

对故障中的车，只允许新鲜且匹配旧nonce、请求集合和会话的实际停稳反馈触发一次重新检查。协调器为重新检查产生新的nonce，速度门重新验证零输出和静止时长。旧证明不转移归属。新检查超时后保持故障，未达到停稳条件的车没有恢复权限。

融合图的栅格路线有重复直角阶梯，短段反复原地转向也可能让可行路线被判断为不前进。新前缀优先查看分配路线近端弧长3.8米内的较远路点，从当前车位试一次连续转向与直行扫掠。只有全车身通过原净空检查时才使用，局部遮挡、急转或未见空间走已有SE(2)搜索与观测视点回退。目标仍落在已分配的图路上，执行前缀仍需取得原有路线进展。

离线用例覆盖旧证明不可解锁、一次新轮次及超时边界，并验证开阔阶梯路径可直达、穿过占据格的捷径被拒绝。
