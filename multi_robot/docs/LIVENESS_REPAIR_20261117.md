# 跨任务重派、图积压与原生内存故障修复

新有限scope为`TOPOLOGY_LIVENESS_LIMITS_20261117.json`：最多4次新Scene4双车，每次含启动收尾wall/sim≤2400秒，失败/中止/崩溃计数。旧全部scope关闭、单机04/Old dual02及历史不替换。使用独立`team_topology_liveness_native_20261117_ws`和`team_topology_liveness_20261117_ws`。本文件先记录离线结果，不能当作95%或T95验收。

## 原生隐患及修复

`GlobalTopoManager::updateNodesRecursion`旧参数是`const cv::Point&`，递归实参指向`heriTopo_[n_label].cvPt`；内部`boost::add_vertex`在`vecS`存储扩容时会使这个引用失效。采用项目实际`LabeledMap/NodeData`的独立扩容用例，旧写法ASan报`heap-use-after-free`；改为值参数后同用例通过。它是已经复现的真实内存隐患，**没有旧03调用栈，不能据此断言是历史SIGSEGV的唯一原因**。

另外修复未找到初始化骨架时使用未初始化坐标、历史单子链递归遇循环/空子节点可能越界、网格cell索引的闭区间上界，以及`conn_num != c_conn_num`未赋值的笔误。空/无效输入返回等待，未伪造自由空间。保留原致命栈诊断、独立进程监视和新鲜里程计停车证明；新原生采用有优化与符号的RelWithDebInfo构建，无在线ASan或调试器插入。

## 重派修复

- 分配器的意图不再直接变成`dispatched`。只有监督器实际发出的ROUTE由`commit_dispatches`提交；STOP/ACK屏障中尚未交付的任务可重新竞标，不再变成无法协助的幽灵占用。
- 已交付/执行任务仍等待旧拥有者真实停车证明；规划接受不等于执行接受、也不等于停车或任务完成。
- `RetryMemory`按本机器人当前位置与前1.5m入口方向暂缓失败路径，任务更名/跨来源不能绕过冷却；退避15/30/45/60秒封顶。不同方向、别的机器人、移动到新位置仍可尝试。`BODY_START_BLOCKED`表示本车起点本身不安全，短期阻断该位置所有入口，不能不断给不同终点来重复失败。
- BLOCKED、当前执行拒绝和无进展停止均记录失败入口，未知区域仍pending；不能把冷却/暂时无人接单当完成。未执行任务可按当前图距离重新归属，已执行任务不抢占。
- 已通过当前执行者完整观测证明的world格支撑，跨任务ID保留完成掩码；换名不能反复派发已观测完的同一区域。新增未知格仍可形成任务，旧拥有者仍等停车证明。掩码不提供占据/自由状态、不生成导航边；只适用于静态共同world，未来坐标图优化或动态场景须另行失效处理。

## 图处理修复

- GraphStore采用copy-on-write原子事务，只深拷贝改变记录并校验改变对象；节点变动还重验已存在的关联边，防止“只校验新边”漏掉旧边端点失配。
- 维护已验证live记录、边关联索引和来源记录索引；失败不修改索引/缓存。tombstone、完整修复、序列冲突、来源/坐标系/根挂接校验保持。
- 图摘要只在记录改变后失效，状态心跳不反复序列化整张历史图。分配竞标与路径重建复用同一轮Dijkstra结果。优先停车事件和源状态3秒新鲜性门槛保留，没有靠放宽过期判断提高覆盖。

实际保存的一条EXECUTOR_REJECTED：目标command_seq179，执行器仅收到178，session/token/version/dispatch相同且stamp有效，stop_pending=false。规划器先收到新命令，但其action跨另一个通道先于执行器的命令订阅到达，立即拒绝又污染当前执行代。现只对尚未收到的命令以steady_clock最多等250ms；等待不持有topology_mutex，独立action线程不会挡住ROS命令回调。等待后重新检查目标时效、STOP、完整租约和命令新鲜性；丢命令、冻结ROS时间都有界退出，已经收到的新STOP绝不被旧ROUTE覆盖。拒绝反馈同时记录last_received_command_seq以便区分最后ROUTE和最新STOP。

原生点路径通过任务约束却可能无法通过整车SE(2)检查。失败时尝试同一任务已有全局图接近路线，仍用本车观测栅格、相同车身扫掠/余量和执行租约；不绕过DEFERRED_TASK。对第1次保存的4张本车栅格和各自此前最后任务路径作纯几何检查（非原生地图重放），3张得到认证接近路径，一张仍BODY_NO_PATH；不声称所有近墙情况已解。原生失败的具体候选没有保存，故该检查不是完整原生决策回放。
