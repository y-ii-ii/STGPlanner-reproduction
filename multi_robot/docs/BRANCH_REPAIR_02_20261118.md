# 分支探索第二版

首跑约第18秒，车2的请求与下发输出接近2 m/s且带小幅正向转向。此后在已下发零输出时，实测角速度短时达到约4 rad/s，停车位的本机格中连零附加余量的车身都有两个占据格重叠。记录支持存在大幅物理偏转，单次记录不足以确定电机和地面的具体原因。

跟踪器现在对非直行普通速度同时缩放平移和角速度，将请求的 `|v×ω|` 限为0.20 m/s²，保持原曲率。检测到仍明显反向旋转时先等待稳定。直行速度上限仍为2 m/s，转向上限、车身净空和最终制动校验沿用原配置。

同一派发的入口仍有合格路径、且与新候选的图距离差不超过0.8米时，优先保持原入口。图更新短时移除任务时，仅在仍有未观测范围、距目标3米以上且旧路仍通过验证时延续最多6秒。接近任务时沿用2秒；已完成任务、实际几何受阻、旧地图和明确STOP仍进入原停车协议。

远离视点时，先判实际图路剩余距离有没有减少。连续18秒没有新观测、没有更接近目标且图路没有缩短，累计又行驶了5米，才按无进展停车并延后该视点。正常绕障可依图距离进展继续。近视点执行停滞或到达期限时只延后该视点，为其他可达分支保留共同入口。

用例覆盖直行上限、弧线曲率、反向旋转时零输出和小成本差下的有效入口保留。所有仿真沿用原Scene4、车型、地图与评分器。

首跑末尾两车的速度门都发布了匹配最终请求的停车证明。收尾脚本读到动作成功状态时，车1的结果消息尚不可读，导致旧汇总错误退出。下一次在原12秒上限内等待实际结果对象，逐车保留收到的证明，缺结果单独记失败。首跑原始结果不回填。
