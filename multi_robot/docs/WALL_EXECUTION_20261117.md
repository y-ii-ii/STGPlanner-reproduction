# 2026-11-17：近墙目标、转向与轨迹执行修复

本轮独立候选，不覆盖成功单机04、Old dual02或2026-11-16交通候选。Scene4、2m/s最大速度、原生独立观测评分、0.4m栅格、7790m²分母和7400.5m²公共阈值保持一致。共同world、完美通信；不引入跨车点云/占据图融合。

## 改什么、为什么

- `body_route.h` / `topology_bridge.cpp`：在原STG五状态给出的同一任务目标附近做有朝向的局部格点搜索。逐段检查车身平移、原地旋转、倒车的扫掠，目标允许停在距参考点0.8m内的已知自由接近区；不要求底盘站在近墙前沿点上。前缀不超过4m，未知和占据不可穿越。没有因此宣布任务完成，完成仍需实际观测证据。不能找到接近路线时，保留待完成任务并反馈阻断。
- `path_execution`：拓扑模式下发布保留朝向的完整路径及绑定任务token/goal_seq的认证路径，替代原先1m前瞻点裁角。其他旧模式不变。认证仅证明当前租约有效，不代表物理执行成功。
- `body_tracking.py` / `topology_velocity_gate.py`：顺序跟踪平移、转向和倒车；仅合并同方向、同朝向、共线段以保持长直线2m/s能力。以本车细栅格检查车身矩形和制动扫掠；未知/过期地图不能放行。制动模型沿用交通策略的2m/s²假设，并增加0.15s延迟、0.25s指令保持和0.10m车身余量；加速按可瞬时到达请求速度估计，不依靠慢加速制造虚假安全。
- `topology_traffic.py`：交通预约接收新跟踪器的速度建议。最终门控在交通批准之后再次检查实际批准速度，覆盖许可晚到、缩放及倒车；STOP/ACK/租约/执行器心跳优先，安全检查只能保留或置零，不能自行启动。
- `topology_coordinator.py`：几何阻断暂缓15s，替代2s快速重发，防止不断重置停滞计时却没有实际位移。停滞仍通过原生恢复入口反馈，不能以超时冒充完成。
- `bench`：新权威额度、结果目录、原生/执行器/Python空间；新增约20Hz车身轨迹诊断与认证路径记录，保留原接触检查、独立评分、停车nonce证明、总wall/sim硬限。

## 方法归属和边界

有朝向格点搜索、顺序路径跟踪和制动扫掠是本项目此次工程适配，不声称复现某篇论文的新算法。原STG五状态仍负责局部探索选点；既有C²式连通任务及GVP-MREP启发的图距离分配保持，未新增论文性能结论。GT位姿、完美通信和共同world假设仍在；尚未实现估计位姿下跨车回环或分布式失联一致性。

离线检查和编译结果以本轮证据为准；在线只允许最多4次新试验，每次含启动/收尾≤2400秒，失败/中止也计数。没有达到95%则T95为空，不能用中止时的短时间/短路程主张更快或更省。仿真接触结果和完整覆盖尚待验证；制动假设、栅格分辨率和观测误差均有局限。

## 第1次诊断后的修正

第1次在307.241s总wall内诊断结束，并集467.04m²/5.9954%，未达95%；双车停止ACK通过、无非地面接触。发现robot1停在0.10m余量可行但0.15m余量不可行的位置；robot2出现118条“仍向前运动、cursor=0却请求倒车”的采样记录（记录条数，不是118次独立事件）。

修正最终跟踪/制动车身余量为与规划一致的0.15m（替代上文最初候选0.10m），避免执行进入规划不允许的近墙带。对滚动替换路径，只在观测位置已沿首条有向线段前进、横向误差<0.14m、朝向匹配时跳过旧起点，不跳过尚未完成的转弯；新增两项回归测试。新试验另存目录；第1次源码/二进制/结果不变。新增完整交通日志及实际执行器二进制断言，便于区分让行等待与静态墙体阻断。

## 第2次诊断后的修正

第2次679.335s总wall诊断结束，955.36m²/12.2639%，总路程104.145m，未达95%；无非地面接触，双车最终停止ACK通过。滚动首点纠偏明显减少，但不能称彻底消除所有倒车；前车后来遇到新观测导致正常余量不足，后车虽有正常车身余量却长期无任务。

- 增加显式`BODY_RECENTER`局部恢复证书：仅在当前实际车身加0.05m余量已知自由、正常0.15m余量被阻断时，搜索代价≤1m的短退离路线，终点必须恢复0.15m余量。恢复不能越过占据或未知；正常路径仍用0.15m。证书随原任务租约传递，最终速度门控独立限制平移≤0.2m/s、转向≤0.3rad/s并检查制动扫掠；不是取消墙体检查或把超时标为完成。几何单测读取已保存的受阻栅格，不启动ROS规划器或地图重放，得到13次展开/3个位姿的可行退离。
- 增加`navigation_history.py`：原导出仅保留当前局部STG/入口路径，更新时删除的历史连接会使双车当前图断开。对第2次历史图做离线诊断，曾广播过的4396段连接形成同一连通分量，而当前双车根的可达样本数相差354/27（不同时间切片不能混作同一统计时刻）。现在按来源保留本车验证过的路径段，每轮以本车地图重新剔除占据/未知段，再压缩度为2的中间节点；分支、环和入口路径采样点保留。仍只共享拓扑/任务，不共享点云/占据图，不做跨机器人SLAM回环。这是长期导航骨架的工程补齐，未实现DTW路径聚类。
- 新增环路双路径保留、障碍/未知使旧桥失效、局部边删除后长期导航仍可路由、恢复证书速度限制等测试；73项Python、31项ASan/UBSan C++检查通过。保留第1/2次所有源、二进制归档和结果，后续试验仍计入同一4次额度。

## 第3次诊断后的最终候选

第3次559.246s总wall诊断结束，最终并集376.80m²/4.8370%，总路程79.058m，无非地面接触，双车停止ACK通过；未达95%。已见实际低速恢复和后续正常路线，当前拓扑图双车根可达样本同为640，后车走出此前停滞位置；这些是机制证据，覆盖/效率没有胜过第2次或历史基线，不能将机制通过冒称更快。

最终候选将SE(2)格点的位置和朝向同时旋转到当前实测车头方向，取消世界轴量化带来的强制首转；所有后续转弯仍检查车身扫掠。完整接近区不可达时，只允许执行朝原参考点有≥0.5m进展、位移≥0.6m、长度≤4m且全程已知自由的`BODY_PREFIX`，不进入未知、不给完成反馈；正常搜索限1600次展开。跟踪器把首位姿当测量锚点，保留后续真实转向，位置偏离且无法确认已沿首段前进时停车等待新规划，不追逐旧起点。新增惯性模型下L型走廊的整段跟踪检查和分配等待原因诊断；76项Python、33项ASan/UBSan C++通过。第4次为本轮最后一次，不补跑第5次。
