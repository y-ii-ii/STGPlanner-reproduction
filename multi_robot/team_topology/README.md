# 共同 world 下的拓扑协同核心

此实现只依赖 Python 标准库，可离线测试。当前方法是图距离分区与任务承诺的地面车适配，不要求实现 MinPos/MDVRP。

- graph.py：来源机器人＋会话＋本地键；逐记录版本、删除记录、原子收包与缺包全量修复；交换的边带已知自由空间路径。导航索引只关联精确重合的路径采样点，不按邻近距离跨墙连边。通信持久记录与本机搜索索引分开，后者目前展开边采样点，不宣称其内存已最优。
- tasks.py：4m格仅作索引；区分格内 free/unknown 连通分量及入口。任务身份跟踪、拆并父项和观测完成证据留在记录中。没有候选、暂不可达或窗口缩小只会 deferred，不会当作完成。
- exporter.py：仅本车使用栅格，验证原STG连接、机器人挂接及任务入口路径。跨车只发送拓扑／任务摘要／机器人状态；不交换完整栅格或点云。
- allocator.py：通过融合图计算真实可达距离；任务多个入口取最小可行代价且只激活一个执行者。先按图距离分工，任务承诺避免轻微代价变化反复换车；仅未执行的任务可直接交接。反馈有版本检查，停滞不等于完成。

已知限制：固定 world 栅格原点／分辨率；不估计位姿，不做真正回环；任务跨源去重采用保守的相同未知摘要＋共用自由入口，局部观测不同仍可能保留重复任务；任务完成证据依赖来源本车地图而非全局真值。所有拓扑边仍须由本车执行前检查，来源边不是动态安全保证。

## 离线验证

在本包目录执行（不需要 roscore）：

    PYTHONPATH=src python3 -m unittest discover -s tests -v

## 方法来源

- [C²-Explorer](https://arxiv.org/abs/2603.07699)：借鉴连通任务／入口组织思想，不移植其地图块共享及飞行执行。
- [GVP-MREP](https://arxiv.org/abs/2408.05808)：借鉴动态拓扑增量交换、图距离分区及跨区协助思想；本实现不照搬三维 EROI、UAV参数或MINCO。
- [MGGPlanner](https://github.com/MISTLab/MGGPlanner)：借鉴跨机器人全局图共享方向。当前精确共同坐标关联不叫SLAM回环。
