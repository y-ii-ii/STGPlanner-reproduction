## 论文与剩余问题

[论文v4 Table I](https://arxiv.org/html/2412.13664v4)对GBP2四场景的时间均使用>号，标准差为横杠；Scene4为>1600s、>1560m。横杠本身只是未提供标准差，结合时间下界不能将其认定为完整成功结果，也不能据此断言程序崩溃。论文正文提及GBP2后期远点往返。

第09轮最终原生地图48次只读重放显示：查询中的残余未知样本XY投影均在公共已知平面内，约84.49%—87.70%的加权未知样本在2m以上。这说明三维残余收益与平面新增量可能分离；它不是唯一根因证明，不能据此反推历史收益或直接更改阈值来宣称成功。
